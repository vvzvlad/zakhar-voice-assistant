### 1. Короткий «захар», августовский сырой пул — `pos_short_fish_raw_pool_2608.*`

Аудио: `Downloads old/pos_short_fish_raw_pool_2608`, 14615 клипов, синтез fish.audio,
медиана 0.694 с. Независимая регенерация тем же скриптом, что и июньский пул на 11997

| Файл | Строк | Что это |
|---|---|---|
| `pos_short_fish_raw_pool_2608.scan.tsv` | 14616 (шапка + 14615) | Независимый ASR-скан всего пула |
| `pos_short_fish_raw_pool_2608.labels.tsv` | 365 (шапка + 364) | Ручная разметка: 273 `good`, 91 `bad` |
| `pos_short_fish_raw_pool_2608.doubtful.order` | 613 | Очередь спорных клипов на ручное прослушивание |
| `pos_short_fish_raw_pool_2608.log` | 494 | Лог генерации пула |
| `pos_short_fish_raw_keep_2608.list` | 9462 | Вычищенные позитивы, годные в обучение |

Разница 14615 против 9462 — принципиальная: в сыром пуле **661** клип, где независимый ASR
услышал «сахар», и 233 пустых по ASR. **Обучение прямо с каталога затянет их в позитивы.**
Брать только то, что перечислено в `.list`.

Число «сахар»-подобных бессмысленно без регулярки и колонки, поэтому определение:

```
cut -f3 pos_short_fish_raw_pool_2608.scan.tsv | grep -ciE 'sahar|сахар'   # → 661
```

Считается **колонка 3 (`text`)** — то, что услышал ASR. 661 = **431** латиницей
(`grep -ciE 'sahar'`: `Sahar.`, `Sahara.`) + **230** кириллицей (`grep -ci 'сахар'`); пересечения
нет, 431 + 230 = 661 ровно.

Латиницей записана НЕ половина скана: из 14615 строк тела **5375** чисто латиницей, **9000**
чисто кириллицей, **7** смешанных, **233** пустых, то есть латиница — **5375 из 14382** непустых
= **37,4 %**. Чисто кириллическая регулярка даёт 230 вместо 661 и занижает счёт в **2,9 раза**
(661 / 230 = 2,87), а не вдвое.

⚠️ Ходившее ранее число **925** — от регулярки `'sahar|сахар|сахара|zahara'` — завышено:
`сахара` ⊂ `сахар` и не добавляет ничего, а `zahara` добавляет 264 строки, где ASR услышал
ровно ЦЕЛЕВОЕ слово («Zahara» = «захара» латиницей). 925 − 264 = 661. Как счёт конфузов
925 не использовать.

91 клип с меткой `bad` материализован отдельно в `Downloads old/rej_short_fish_raw_badgen_2608`
(побайтовые копии, не отдельный набор).

## Колонки

`*.manifest.tsv` — что просили синтезировать (7 колонок, с шапкой):

```

```

`*.scan.tsv` — что независимый ASR реально услышал плюс акустика (10 колонок, с шапкой):

```
conf  score  text  dur  rms_dbfs  peak_dbfs  clip_frac  sil_head  sil_tail  file
```

`*.labels.tsv` — ручная разметка (2 колонки, с шапкой): `file  label`, где `label` ∈ `good` / `bad`.

`*.keep.list`, `*.list`, `*.doubtful.order` — по одному имени файла в строке, без шапки и
без путей. Имена базовые, поэтому переименование каталога с аудио их не ломает.

`*.gen.log` — текстовый лог генератора: параметры прогона, оценка стоимости, путь вывода.
